# Bases de datos del curso

Este repositorio es público, así que **no guarda bases de datos**. Los cuadernos las descargan desde su fuente oficial o indican cómo solicitar acceso.

| Base | Qué contiene | Acceso |
|---|---|---|
| [MIMIC-IV Demo](https://physionet.org/content/mimic-iv-demo/) | Cuidados intensivos, 100 pacientes | Abierto (ODbL) |
| [MIMIC-IV](https://physionet.org/content/mimiciv/) | Cuidados intensivos, versión completa | Credenciamiento en PhysioNet + curso CITI |
| [PPMI](https://www.ppmi-info.org/access-data-specimens/download-data) | Enfermedad de Parkinson, longitudinal | Solicitud gratuita |
| [NHANES](https://wwwn.cdc.gov/nchs/nhanes/) | Encuesta de salud y nutrición de EE. UU. | Abierto |
| [ENDES](https://proyectos.inei.gob.pe/microdatos/) | Salud materno-infantil, Perú (INEI) | Abierto |
| [SINADEF](https://www.datosabiertos.gob.pe/) | Registro nacional de defunciones, Perú | Abierto |
| [Global Burden of Disease](https://vizhub.healthdata.org/gbd-results/) | Carga de enfermedad por país, edad y sexo | Abierto, con registro |
| [Catálogo neuro2.ai](https://datasets.neuro2.ai) | Índice de más de 1,000 datasets de neurociencia | Según cada fuente |

## Reglas

- **Nunca** suba al repositorio datos de MIMIC-IV completo ni de PPMI: sus acuerdos de uso prohíben redistribuirlos. Esto incluye subconjuntos, tablas derivadas y salidas de celdas que muestren filas de pacientes.
- Para las bases abiertas, prefiera que el cuaderno descargue el archivo desde la URL oficial en lugar de copiarlo aquí.
- El `.gitignore` bloquea los formatos de datos más comunes como red de seguridad, pero no reemplaza revisar lo que se sube.
